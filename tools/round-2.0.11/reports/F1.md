Method notes (so the results can be judged):
- Every click is a real DOM click on the plugin's own buttons (`.tm-pl button`, `.tm-op .bb button`, `#tm-confirm .y`, the presentation's own buttons); drags, wheel and keys in `input.mjs` are real Playwright mouse / keyboard events.
- The plugin swallows exceptions in its click handlers (`70-ui.js:1751-1754` `try { row.onPick(key) } catch (_) {}`, `3136-3139` `try { it.action() } catch (_) {}`), so a broken option would NOT show in the console. I wrapped every row's `onPick` / `fly`, every place's `action` and every feature's `on` / `off` to record what they throw (reported as SWALLOWED).
- "Model changed" = a fingerprint of every effectively visible mesh (world matrix + geometry id; `__q.sig`) plus a material fingerprint (colour / map / emissive / opacity of meshes that the wall-fading does not touch). Things that move by themselves (fire, smoke, water) are excluded. "State leak" = the fingerprint at "מבט כללי" before a row against the fingerprint at "מבט כללי" after cycling through the row and returning to its default chip, plus the list of features / on-model buttons / section / layers.
- The machine was heavily overloaded by parallel reviewers (load average 15–25 on 2 cores; my pages crashed about ten times with "Target crashed" when the shared memory limit was reached). Each real draw took 30–50 s, so I drew far fewer pictures than planned; see COVERAGE.
